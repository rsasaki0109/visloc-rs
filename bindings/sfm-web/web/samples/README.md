# Samples

Photo sets the page offers, listed in `samples.json` (name, folder, files,
the focal length in pixels at this size, and the credit line).

| Sample | Photos |
|---|---|
| `courtyard` | ETH3D high-resolution multi-view, *courtyard*: the 38 undistorted DSLR photos, shrunk to 800x534 (JPEG). Focal 440 px at this size (the dataset's 880 at 1600 px, halved). |
